# How to Create a New User on Windows

Creating a new user account in Windows is a basic but essential IT Support task. Here's how:

## 🔹 Steps:
1. Open the **Start Menu**, type `lusrmgr.msc`, and hit Enter.
2. In the Local Users and Groups window, right-click on **Users** > choose **New User**.
3. Enter username, password (optional), and uncheck "User must change password" if needed.
4. Click **Create**, then **Close**.
5. (Optional) Add the user to groups like "Administrators" or "Remote Desktop Users".

✅ Done! You’ve created a new local user.
