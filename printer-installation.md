# How to Install a Printer on Windows

Installing a printer is a common IT Support task, especially in offices or schools. Here's how to do it:

## 🔹 Steps:

### 🖨️ Option 1: Add a Network or Wireless Printer
1. Open **Settings > Devices > Printers & Scanners**
2. Click **Add a printer or scanner**
3. Wait for the system to detect the printer
4. Select it and click **Add device**

### 🖨️ Option 2: Install a Local Printer with USB
1. Connect the printer via USB
2. Windows should detect and install the printer automatically
3. If not, go to **Control Panel > Devices and Printers** and click **Add a Printer**
4. Select **Use an existing port (USB001)** and follow the wizard

## 🔧 Troubleshooting:
- Make sure the printer is powered on
- Check Wi-Fi or cable connection
- Update or reinstall drivers if needed

✅ That’s it — your printer should now be ready to use!
