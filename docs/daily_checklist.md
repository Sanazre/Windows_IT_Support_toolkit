# Daily IT Support Checklist (All OS)

## Windows
- [ ] Run Windows Updates
- [ ] Check Windows Defender status
- [ ] Clean temp files and logs
- [ ] Verify backups
- [ ] Ensure printers and network are functional

## Linux
- [ ] Check system logs: `journalctl -p err`
- [ ] Check disk usage: `df -h`
- [ ] Restart important services: `sudo systemctl restart networking`
- [ ] Verify cron jobs and updates

## macOS
- [ ] Check system updates: `softwareupdate -l`
- [ ] Verify Time Machine backups
- [ ] Monitor Activity Monitor
- [ ] Restart networking if issues
